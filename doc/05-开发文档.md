## 2. 基础设施（docker-compose）

> 现有仓库根目录 `docker-compose.yml` 目前只有一行 `services:`（空壳）。
> 建议替换为以下内容。**注意：仓库文件本任务未修改，请你确认后再落盘。**

```yaml
services:
  postgres:
    image: pgvector/pgvector:pg16
    container_name: wenqu-postgres
    environment:
      POSTGRES_DB: wenqu
      POSTGRES_USER: wenqu
      POSTGRES_PASSWORD: wenqu@123
      # 中文分词扩展需自定义镜像并安装 zhparser/pg_jieba，见 §2.1
    ports:
      - "5432:5432"
    volumes:
      - pgdata:/var/lib/postgresql/data
    healthcheck:
      test: ["CMD-SHELL", "pg_isready -U wenqu -d wenqu"]
      interval: 5s
      timeout: 3s
      retries: 10

  minio:
    image: minio/minio:latest
    container_name: wenqu-minio
    command: server /data --console-address ":9001"
    environment:
      MINIO_ROOT_USER: wenqu
      MINIO_ROOT_PASSWORD: wenqu@123456
    ports:
      - "9000:9000"   # S3 API
      - "9001:9001"   # 控制台
    volumes:
      - minio_data:/data
    healthcheck:
      test: ["CMD", "mc", "ready", "local"]
      interval: 5s
      timeout: 3s
      retries: 10

volumes:
  pgdata:
  minio_data:
```

启动：`docker compose up -d`

### 2.1 中文 BM25 分词（可选但推荐）

默认 `kb_chunk.tsv` 使用 `to_tsvector('simple', content)`。中文分词效果差，两种增强方式：

- **方式 A（推荐）**：自定义 Dockerfile 安装 `zhparser` 或 `pg_jieba`，然后：
  ```sql
  CREATE EXTENSION zhparser;
  CREATE TEXT SEARCH CONFIGURATION chinese (PARSER = zhparser);
  ALTER TEXT SEARCH CONFIGURATION chinese ADD MAPPING FOR n,v,a,i,e,l WITH simple;
  -- 把生成的表达式改为 to_tsvector('chinese', content)
  ```
- **方式 B（零依赖）**：应用层用 Jieba 分词，把空格分隔的结果写入 `tsv`（改为普通列 + 应用维护），
  BM25 查询时对 query 同样分词。

> 该选择影响 `03-数据库设计.md` 中 `kb_chunk.tsv` 的定义，请先在 [`06`](./06-待确认事项.md) 确认。

## 5. 编码规范

### 5.1 Java

- 分层：`Controller → Service → Repository`；**Controller 不写业务**，Service 不碰 `HttpServletRequest`。
- DTO 与实体分离：`dto/request/*`、`dto/response/*`，实体仅内部使用。
- 校验：`@Valid` + JSR-380 注解；业务规则在 Service 抛 `BizException`。
- 异常：统一 `GlobalExceptionHandler`；禁止吞异常（至少 `log.warn` + 重抛或转换）。
- 事务：`@Transactional` 只加在 Service 的写方法；**注意**：SSE 生成过程不要长时间持有事务。
- 日志：`@Slf4j`；关键路径带 `traceId`；禁止打印 `apiKey`/`password`/完整 SQL 结果集。
- 命名：类 `UpperCamel`，方法/变量 `lowerCamel`，常量 `UPPER_SNAKE`，包全小写。
- 注释：仅在"为什么"不显然时写；禁止逐行解释"是什么"。
- 时间：统一 `OffsetDateTime`；DB 用 `timestamptz`。
- 金额：`BigDecimal`，禁止 `double` 做金额计算。

### 5.2 TypeScript / React

- 函数组件 + Hooks；禁止类组件。
- 服务端状态用 TanStack Query，客户端状态用 Zustand；**不要**把服务端数据塞进 Zustand。
- 类型：API 类型集中在 `types/`，与 `04-API接口规范.md` 字段一一对应（camelCase）。
- 请求统一走 `lib/http.ts` 的 axios 实例（注入 token、统一错误处理）。
- 组件命名 `PascalCase`，文件同名；hooks 以 `use` 开头。
- 禁止在 JSX 里写复杂逻辑，抽到 hooks。
- Tailwind：优先原子类；重复样式抽到 `components/ui`。

### 5.3 Git

- 分支：`main`（稳定）、`develop`（集成）、`feat/*`、`fix/*`。
- 提交信息：`feat(kb): 支持批量上传文档` / `fix(sqlbot): 修正 LIMIT 追加逻辑`（Conventional Commits）。
- 提交前：后端 `./mvnw -q verify`；前端 `pnpm lint && pnpm build`。
