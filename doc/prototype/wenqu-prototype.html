SQL
识别指标「销售额」与维度「区域」，关联 sales_order × customer
引用口径知识库「业务指标口径库」：销售额 = 已完成订单金额合计
安全校验通过（只读 · 已自动追加 LIMIT 5）
生成 SQL · prod-pg-01 
SELECT c.region,
       SUM(o.amount) AS total_amount
FROM sales_order o
JOIN customer c ON c.id = o.customer_id
WHERE o.status = 'COMPLETED'
  AND o.created_at >= '2026-09-01'
  AND o.created_at <  '2026-10-01'
GROUP BY c.region
ORDER BY total_amount DESC
LIMIT 5;   -- 系统自动追加
口径说明：销售额 = 状态为 COMPLETED 的订单金额合计，统计区间 2026-09-01 ~ 2026-09-30。
