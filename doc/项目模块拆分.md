
# 通用模块

**common** 无业务依赖的通用能力

**config**     全局配置装配

**security** 认证鉴权基础设施

# 业务模块

| 模块              | 对应需求           | 核心职责                                                     |
| --------------- | -------------- | -------------------------------------------------------- |
| `auth`          | 认证与会话          | 登录、刷新、登出、当前用户信息、改本人密码                                    |
| `user`          | 用户管理           | 用户 CRUD、启用禁用、重置密码、删除（仅 SUPERADMIN）                       |
| `model`         | 模型配置 + 全站模型网关  | 多供应商模型 CRUD、连通性测试、默认模型；`LlmGateway` 统一 chat/embed/rerank |
| `knowledgebase` | RAG 知识库管理      | 知识库/文档/分片 CRUD、检索测试、摄入流水线                                |
| `chat`          | 智能问答           | RAG 会话、消息、SSE 流式问答、引用溯源、反馈/重新生成                          |
| `sqlbot`        | SQLBot         | 数据源、Schema 同步、NL2SQL、SQL 安全校验、执行、图表、导出                   |
| `system`        | 系统参数/操作日志 + 统计 | 系统参数、操作日志、Dashboard 统计                                   |
