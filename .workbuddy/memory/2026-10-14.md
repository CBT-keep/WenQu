排错条目（均有实战依据）：
1. java 显示 21 但项目要 17 —— 不是问题，--release 17 保证产物是 17 字节码
2. docker: command not found / docker-credential-desktop not found —— 终端 PATH 未刷新
3. in-toto attestation 404 —— 加速源不同步供应链证明，镜像层已下完，重跑即可
4. 加速源拉不动 —— curl -I <源>/v2/ 自检，长期用阿里云个人专属地址
5. pnpm-lock.yaml 冲突 —— 大版本 lockfile 格式不兼容，团队必须统一
6. 端口占用 / 推倒重来
